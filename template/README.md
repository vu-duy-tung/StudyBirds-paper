# Official IJCAI 2027 template

Downloaded on 20 November 2026 from the [official IJCAI Author's Kit](https://ijcai.org/authors_kit/):

https://ijcai.org/sites/default/files/Guidelines/FormattingGuidelines-IJCAI-27.zip

The original LaTeX and BibTeX examples are preserved here. `../ijcai27.sty` and `../named.bst` are unchanged copies from the same archive. The Word template is omitted because this project uses LaTeX. Original notices and credits remain in the supplied files; this repository does not relicense them.

`../main.tex` is the editable StudyBirds entry point. It is adapted from the example, retains the required template metadata, and adds a XeTeX/Tectonic compatibility branch. Do not select the original example as the Overleaf main document.
